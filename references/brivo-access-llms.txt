## Browser / SPA Integration

Browser-based apps cannot call auth.brivo.com or api.brivo.com directly due to
CORS restrictions. Use a dev-server proxy (e.g., Vite, webpack) that rewrites
paths so the local routing prefix is stripped before forwarding:

| Local prefix | Target | Example |
| --- | --- | --- |
| `/auth` | https://auth.brivo.com | `/auth/oauth/token` -> `https://auth.brivo.com/oauth/token` |
| `/api` | https://api.brivo.com  | `/api/v1/api/sites` -> `https://api.brivo.com/v1/api/sites` |

## Filter Syntax (applies to every `filter=` query parameter)

Format: `<field>__<op>:<value>[,<value>...]`

- Operators: `eq`, `ne`, `gt`, `lt`
- Multiple values for one filter: comma-separated (`id__eq:11,22,33`)
- Multiple filters in one request: semicolon-separated (`site__eq:111;occurred__gt:2024-01-01T00:00:00Z`)

Common mistakes that return `400 "Invalid filter format"`:

- Using a single `:` between field and operator (`site:eq:111`) instead of `__` (`site__eq:111`)
- Joining filters with `,` instead of `;`

Per-tag reference files list available filter fields and per-field constraints
(for example, `occurred` on `/events/access` is capped to a 24-hour window),
but the syntax above is universal across the Access API.

## Token Lifetime and Refresh

The `access_token` returned by the password grant expires in **300 seconds**.
This is short enough that any multi-call flow (login -> list sites -> list
events) will outlive a single token. Refresh is mandatory, not optional.

Required client behavior:

1. Persist the `refresh_token` returned alongside `access_token`.
2. Refresh proactively before `expires_in` elapses, OR retry once on
   `401 {"error":"invalid_token"}` using `grant_type=refresh_token`.
3. Only force the user to re-authenticate if the refresh request itself fails.

Refresh request:

```http
POST https://auth.brivo.com/oauth/token
Authorization: Basic {BASE64_ENCODED_CLIENT_CREDENTIALS}
api-key: {api-key}
Content-type: application/x-www-form-urlencoded

grant_type=refresh_token&refresh_token={REFRESH_TOKEN}
```
